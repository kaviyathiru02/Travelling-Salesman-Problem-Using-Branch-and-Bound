# Travelling-Salesman-Problem-Using-Branch-and-Bound

Python and Streamlit implementation of the Travelling Salesman Problem to find the optimal tour and minimum travelling cost using a predefined cost matrix.

## Features

Displays a 5-city cost matrix,
Finds the optimal tour,
Calculates the minimum travelling cost,
Interactive Streamlit interface.

## Technologies

Python,
Streamlit.

## Run

pip install -r requirements.txt

streamlit run app.py
